# Inspection views

Neutral inspection shading only; source contains no materials/textures. These images are static reference renders, not skinning evidence. Manny is the existing read-only project reference. Side-by-side: blue Manny left, raw Meshy right. Overlay: blue Manny and orange rigid height-fitted Meshy, with no skin or pose transfer. Unreal fixture: fitted Meshy left, Manny centre, raw Meshy right; its headless capture has limited shadow detail and is used for placement/orientation only. Blender views provide the readable geometry closeups.
