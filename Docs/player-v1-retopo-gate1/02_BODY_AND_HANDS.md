# Body and hands

New connected torso/shoulder armholes and branching hip/crotch topology, separated legs, elbow/wrist/knee/ankle support rings and a neck interface. Hidden anatomy is deliberately simple. Body has 4,030 triangles; hands 3,592. Arms use 16-vertex cross sections, legs 24; shoulder/clavicle, elbow, wrist, pelvis, knee and ankle centres derive from existing Manny rest joints. Module interfaces use deliberate closed end caps/coverage seams, not claims of a seamless exposed nude body.

Hands are rebuilt as connected quad palms with four finger branches and a thumb branch per hand. Five distinct digits have individual Manny finger influences, max four weights/vertex. No fused source fingers are preserved. Neutral-hand screenshots prove separation, not a successful sword grip.

BLOCKER: guard/attack closeups show the hand still open below the correct existing jian hilt. Individual digits can deform, but operational grip is not accepted. Next work must correct palm/phalange placement and finger weighting/asset pose compatibility against the unchanged SwordGrip_R/JianGripTransform; changing the sword to hide this failure is prohibited. Do not compensate with gameplay code.

Underbody Jump/Landing edge strain reaches 3.79x / 3.32x; coarse joint transitions, shoulder/armpit/elbow and hip coverage need targeted loop/weight refinement before a polish-only gate. General manifold validation is not deformation acceptance.

The uncovered pelvis closeup also shows a shelf at the thigh transition and a pointed crotch bridge. These need geometric reconstruction/smoothing of the control loops before weight polish; they are not an anatomically accepted hidden body merely because the mesh is manifold. Boot/ankle interfaces remain coverage seams rather than a seamless exposed foot.
