# Deformation matrix

Ten existing accepted Manny clips, seven times each (0, 1/6, 2/6, 1/2, 4/6, 5/6, 1). Midpoint pictures plus guard/attack grip and meditation back detail. All 70 samples have finite vertices. Structural check PASS means valid imported skeleton/weights only; visible grip/clipping and strain failures below prevent acceptance. No pose is falsely passed because the mesh merely stayed finite.

Clip paths, bounds, per-module edge ratios and exported midpoint OBJ are in evidence/engine-deformation.json and the evidence bundle engine/ directory. Skinning uses imported UE LOD0 data. Captures are neutral Blender views of those exact positions with inspection normals; no pose was generated by AI or painted into a screenshot. Full continuous motion, runtime MM/IK correction and unsampled interpenetrations are not certified. Formal triangle-triangle self-intersection certification was not performed.
